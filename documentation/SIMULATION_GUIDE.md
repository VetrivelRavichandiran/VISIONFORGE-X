# VISIONFORGE X - Simulation Guide

## Overview
Simulation mode enables full platform operation without physical hardware. All synthetic data is explicitly labeled SIMULATED.

## Starting Simulation
1. Launch application
2. Default mode is simulation
3. Click Connect → SimulationDevice connects instantly

## Simulated Components

### Video Stream
- Generated by `SimulationDevice.generate_frame()`
- Moving gradient pattern with animated shapes
- Configurable noise level
- Resolution matches preview settings

### Telemetry
- Synthetic FPS, latency, CPU, memory values
- Randomized within realistic ranges
- Motion intensity and anomaly scores
- All values labeled SIMULATED in reports

### Events
- Device connect/disconnect
- Camera start/stop
- Processing start/stop
- Benchmark start/complete
- Simulated failures

### Failure Injection
- Disconnect simulation
- Network timeout simulation
- Command rejection
- Reconnection flow

## Configuration
In System Configuration:
- `simulated_fps`: Target FPS (default 30)
- `simulated_latency_ms`: Base latency (default 15)
- `noise_level`: Frame noise (default 0.02)

## Reproducibility
Use deterministic seeds for testing:
```python
import numpy as np
np.random.seed(42)
```

## Testing Without Hardware
All features work in simulation:
- Vision algorithms
- Motion detection
- AI inference (simulated)
- Pipeline editing
- Benchmarking
- Reports
