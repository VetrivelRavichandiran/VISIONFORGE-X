# 📜 Changelog

All notable changes to VISIONFORGE X will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of VISIONFORGE X platform
- 12-page desktop application with PySide6 GUI
- 16 computer vision algorithms with parameterized pipelines
- Motion intelligence module (frame differencing, background subtraction, tracking)
- Anomaly detection laboratory with scoring and heatmaps
- AI model registry with ONNX Runtime support
- Visual pipeline architect with validation
- FPGA monitor with resource utilization telemetry
- Real-time performance benchmarking (FPS, latency, throughput)
- Dataset explorer with import, browsing, and validation
- Event intelligence with search, filtering, and export
- Research report generation (PDF, CSV, JSON)
- System configuration with SQLite persistence
- TCP/UDP communication protocol for ZYBO Z7-10 hardware mode
- Simulation mode for hardware-free operation
- Comprehensive test suite (pytest, pytest-qt)
- Full documentation suite (11 technical documents)
- Professional GitHub repository structure

### Changed
- Enhanced design system with obsidian backgrounds and vibrant accent colors
- Improved navigation rail with gradient logo area
- Upgraded all page layouts with glow effects and modern styling

### Fixed
- Startup crash bugs across all 12 pages
- Deprecated DPI attribute warnings in main application
- Panel double-layout warnings throughout the frontend
- Threshold default values in vision engine
- Pipeline engine MORPH_* constant definitions
